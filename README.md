# recetas-ulises
Personal digital cookbook built with Next.js, Supabase and AI-assisted development.

## Flujo de trabajo

Cada nueva funcionalidad sigue el siguiente proceso:

1. Definir o actualizar la especificación en `specs/`.
2. Revisar el impacto en la arquitectura y documentación.
3. Solicitar a Antigravity un plan de implementación.
4. Revisar el plan.
5. Implementar la feature.
6. Revisar los cambios generados.
7. Ejecutar `npm run lint` y `npm run build`.
8. Realizar el commit correspondiente.
