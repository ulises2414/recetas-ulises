# Visión del producto

Recetas Ulises nació como un recetario digital personal.

Muchas de las recetas fueron obtenidas de videos, páginas web, Instagram, YouTube, amigos o familiares. Con el tiempo fueron modificadas según mi experiencia y preferencias.

El objetivo no es recopilar miles de recetas, sino conservar aquellas que realmente preparé y que volvería a cocinar.

El sitio busca resolver un problema muy común: cuando queremos repetir una receta que nos gustó, muchas veces no recordamos cuál fue la versión utilizada ni qué modificaciones realizamos.

Cada receta representa una versión validada por experiencia propia.

Aunque el sitio está pensado principalmente para uso personal y para compartir con amigos y familiares, cualquier visitante podrá utilizar las recetas como referencia.

La filosofía del proyecto es la de un cuaderno de cocina digital más que la de un portal gastronómico.
